# Conversion Copywriting Agent Skill

Write clearer, more specific, more credible copy for websites, products,
portfolios, SaaS, onboarding, CTAs, social content, and other persuasive
user-facing writing.

`writing-conversion-copy` is a reusable Agent Skill for AI coding and
productivity agents that need to write, rewrite, critique, or tighten copy
without falling into generic marketing language or repetitive AI-writing
patterns.

## What It Helps With

Use this skill for work such as:

- website, landing-page, SaaS, product, and portfolio copy
- headlines, hooks, value propositions, CTAs, onboarding, and UX microcopy
- social posts, captions, email copy, positioning, and brand messaging

It can work from a blank page or improve copy that already exists.

## What It Optimizes For

The skill prioritizes three things:

- **Clarity:** the reader should understand the value quickly
- **Credibility:** claims stay proportional to the available evidence
- **Momentum:** the copy makes the next step obvious without unnecessary padding

The goal is persuasive writing that still sounds human.

## Core Writing Principles

### Make the value obvious

Lead with the reader's situation, desired outcome, or reason to care.

Explain implementation after relevance is established when that order improves
clarity.

### Make the copy easy to scan

Use specific headlines, short sections, useful hierarchy, and concise
paragraphs.

Each section should have one primary job.

### Keep claims honest

Never invent metrics, testimonials, customer counts, performance results,
partnerships, awards, or other proof.

Put available evidence close to the claim it supports.

## Patterns It Actively Avoids

The skill checks for common writing patterns that weaken otherwise useful copy:

- generic openings, filler, vague claims, and corporate padding
- repetitive antithesis, manufactured aphorisms, and unnecessary em dashes
- fabricated authority, generic motivational language, and AI-sounding rhythm

These are writing checks, not absolute grammar rules. Context and the user's
requested voice still take priority.
